# imgr 사용법

English: [usage.md](usage.md)

imgr.exe 가 있는 폴더가 imgr의 자리입니다. 그 옆에 `imgs\`(그림)와 `data\`(기록)가 생깁니다.
다른 곳을 쓰려면 환경 변수 `IMGR_ROOT` 에 폴더를 지정하세요.

## 켜기

```text
imgr.exe 더블클릭. 켜면 imgs 폴더를 읽어 새 그림·옮겨진 그림·사라진 그림을 정리하고 바로 목록을 보여 줍니다.
이미 켜져 있으면 새 창을 띄우지 않고 켜져 있는 창을 앞으로 가져옵니다 (윈도우 신호로, 네트워크 안 씀).
모든 그림은 imgs\00001, 00002 … (한 폴더에 2000장씩, 위 ⚙ 설정에서 바꿈) 에 둡니다. 폴더는 imgr이 알아서 채웁니다.
점수·태그·앨범·필터는 data\imgr.db (SQLite) 에 저장, 바뀐 그림만 씀 (data\backup = 날마다 하나씩 14일치, imgr_날짜.db).
저장은 통째로 되거나 안 되거나라서 도중에 꺼져도 깨지지 않습니다. imgr.db 를 못 읽으면 읽기만 하고 저장하지 않습니다 (data\backup 의 사본을 imgr.db 로 복사해 되살림).
v0.16 이하의 data\db.json 은 v0.20 을 처음 켤 때 한 번 옮기고 db.json.v016 으로 남깁니다 (그 뒤로 예전 판은 이 data 를 열지 않음).
파일 내용으로 그림을 알아보므로, imgs 안에서 파일을 옮기거나 이름을 바꿔도 점수·태그는 그대로 따라갑니다.
창 크기·위치, 양옆 칸 너비, 마지막에 보던 그림은 다음에 켤 때 그대로.
```

## 화면

```text
위: ⚙ 설정 · 검색칸 · 최근 검색(▾) · 정렬 · 가져오기 · ⟳   (보기는 왼쪽 앨범 뷰·검색 뷰, 크게 = Enter, 비교열 = C·[비교열], 표 = M)
⚙ 설정: 언어(한국어 / English, 누르면 바로 바뀜) · 폴더 하나에 넣는 그림 수 · 스크립트 조작 허용 · 사라진 그림 기록 지우기
왼쪽: 🗂 앨범 뷰 (/ = 맨 위 · 앨범 나무 · 휴지통. 줄 어디를 눌러도 됨)
      ▦ 검색 뷰 (전체 보기 · 저장한 검색 · 점수(N/A = 점수 없음) · 해시태그 · 앨범 · 체크포인트 · LoRA · 태그 여부 · 폴더) (제목 누르면 접힘)
  태그 여부: 워크플로 = ComfyUI 정보(프롬프트·체크포인트·시드)가 든 그림, 태그없음 = 그 정보가 없는 그림(jpg 등).
             둘 다 켜면 모두, 하나만 켜면 그것만. 처음엔 워크플로만. 앨범 뷰·휴지통에는 적용 안 됨.
           검색 뷰 목록의 숫자도 이 거름을 따름 (누르면 보이는 수와 같음).
  (폴더 = imgs 안의 진짜 폴더 00001… / 앨범 = imgr 안에서만 쓰는 분류)
  해시태그·체크포인트·LoRA·폴더·앨범: 클릭 = 검색에 넣기·빼기 (검색칸 왼쪽 AND/OR 에 따라), Ctrl+클릭 = 그 종류는 이것만
오른쪽: 고른 그림 미리보기 · 프롬프트 · 점수 · 해시태그 · 정보(패스 = imgs 안의 폴더/파일 이름)
  "탐색기에서 보기" = imgs 안에서 그 그림이 있는 폴더를 열고 그림을 골라 둠
양옆 칸은 경계선을 마우스로 끌어 너비 조절. 오른쪽 미리보기 왼쪽 아래 모서리 손잡이(▧)를 끌면
오른쪽 칸 너비와 미리보기 높이가 같이 바뀜. [ ] 키로 왼쪽/오른쪽 칸 숨기기·보이기. F11 전체 화면.
```

## 그림 넣기

```text
・창 위로 파일이나 폴더를 끌어다 놓기 → 복사해서 imgs에 넣음
・탐색기에서 파일 복사(Ctrl+C) → imgr에서 Ctrl+V
・위 "＋ 가져오기" → 폴더 경로 입력 (하위 폴더 포함). "옮기기"를 고르면 원래 폴더에서 빠짐
・자동 가져오기: "＋ 가져오기" 창 아래에 폴더를 추가해 두면, imgr가 켜져 있는 동안 1분마다 새 그림을 복사해 옴
  (예: ComfyUI의 output 폴더). 처음 추가할 때 그 폴더에 이미 있는 그림도 들어옵니다.
  data_blind…, _for_kohya…, 점(.)으로 시작하는 하위 폴더는 들어가지 않습니다.
・내용이 같은 그림이 이미 있으면 건너뜀 (이름이 달라도 같은 그림은 한 번만)
・이름만 같고 내용이 다르면 '이름 (2).png'처럼 바꿔서 넣음
・앨범을 연 채로 넣으면 그 앨범에도 들어감 (이미 있던 같은 그림도)
・탐색기로 imgs에 직접 넣은 파일도 켤 때·F5·45초마다 저절로 등록
```

## 보기·고르기 (탐색기와 같게)

```text
클릭 = 하나 / Ctrl+클릭 = 더하기·빼기 / Shift+클릭 = 범위 / Ctrl+A = 보이는 것 모두
고르지 않은 그림 위나 빈 곳에서 끌기 = 네모로 여러 장 고르기 (Ctrl·Shift 누르면 지금 고른 것에 더함)
빈 곳 클릭 = 고른 것 풀기
방향키로 이동 (Shift+방향키 = 범위), PageUp/Down, Home/End
더블클릭·Enter·Space = 크게 보기
Ctrl+휠 또는 아래 오른쪽 막대 = 썸네일 크기.  아래 "파일 이름" = 썸네일 밑 파일 이름 보이기
이미 고른 그림을 끌어서 앨범(왼쪽 앨범 목록·앨범 화면의 앨범)에 놓으면 그 앨범에 넣음 (앨범 뷰 안에서는 옮기기, Ctrl = 복사)
창 밖으로 끌고 나가면 탐색기·브라우저 업로드 칸 등에 파일이 그대로 넘어감
  (고르지 않은 그림은 한 번 클릭해 고른 뒤 끌기. 끄는 중 Esc = 그만두기)
오른쪽 클릭 = 메뉴 (크게 보기·비교열에 추가·점수·태그·앨범·이름 바꾸기·내보내기·복사·탐색기에서 보기 …)
```

## 크게 보기

```text
휠 = 확대 (마우스 자리 중심), 끌기 = 이동, R = 맞춤, Z = 실제 크기(1:1)
← → 또는 마우스 앞/뒤 버튼 = 넘기기.  Esc = 돌아가기
1~6 점수를 주면 다음 그림으로 넘어감 (아래 "점수 후 다음" 끄면 안 넘어감)
위쪽에 파일 이름·점수·태그, 둘째 줄에 체크포인트·시드, 아래쪽에 키 안내.  ` = 이 글들 숨기기/보이기.
```

## 점수 (1~6)

```text
키보드 1~6, 0 = 지우기 (` 도 지우기, 크게 보기에서만 글 숨기기).  왼쪽 N/A = 점수 없는 그림만. 오른쪽 숫자 단추도 같음. 여러 장 고르면 모두에 적용.
썸네일 왼쪽 위 동그라미가 점수. 왼쪽 점수 막대 = 점수별 장 수.
정렬 "무작위(채점용)" = 순서 영향 없이 채점할 때.
```

## 해시태그

```text
T 누르고 입력 후 Enter (여러 개는 쉼표나 띄어쓰기로). Tab = 자동 완성. 입력칸은 Enter 뒤에도 남아 있어 이어서 입력 가능.
오른쪽 "빠른 태그" 단추 = 최근·자주 쓴 태그 한 번에 붙이기 (모두 붙어 있으면 뗌)
태그 칩을 누르면 그 태그로 검색, 옆 ✕ = 떼기. 빈 입력칸에서 Enter = 입력 끝내기.  썸네일 오른쪽 위 #2 = 태그 개수.
왼쪽 해시태그 오른쪽 클릭 = '이것 빼고' 검색 · 고른 그림에 붙이기/떼기 · 이름 바꾸기(같은 이름이면 합치기) · 모두에서 떼기
```

## 이름 바꾸기 (F2)

```text
한 장: 확장자 빼고 이름이 골라진 채로 열림 → 입력 → Enter
여러 장: "이름_###" 틀 + 시작 번호 (# 개수 = 자릿수), 또는 업로드용 무작위 이름(11자, 시간순)
같은 이름이 있으면 바꾸지 않고 알려 줌. 오른쪽 칸 파일 이름 더블클릭도 같음.
```

## 내보내기 (Ctrl+E) — 업로드용 복사본

```text
고른 그림을 다른 폴더에 복사. JPG/PNG는 ComfyUI 프롬프트 정보를 지움 ("원본 그대로"는 안 지움).
업로드용 무작위 이름, 내보낸 그림에 해시태그(예: pixiv) 자동으로 붙이기. 설정은 다음에도 기억.
```

## 복사·붙여넣기

```text
Ctrl+C = 고른 그림 복사 (탐색기·업로드 창에 붙여넣기도 됨)
Ctrl+X = 고른 그림 잘라 두기 (앨범 옮기기용. 파일은 그대로)
Ctrl+V = 열린 앨범에 붙이기:  Ctrl+C 한 그림은 그 앨범에도 같이 들어감 (여러 앨범에 동시에)
                             Ctrl+X 한 그림은 자른 앨범에서 빠지고 이 앨범으로 옮겨짐
         탐색기에서 복사한 파일이면 imgs로 가져오기 (앨범이 열려 있으면 거기에도 넣음)
Ctrl+Shift+C = 파일 경로를 글자로 복사
```

## 찾기 (위 검색칸, Ctrl+F 또는 /)

```text
#pixiv            태그 있는 것          -#pixiv   태그 없는 것
score>=4  score:5  score:0(점수 없음)
preset:photoB   ckpt:obsess   lora:pastel   seed:12345   folder:00001   name:003640
is:unscored  is:untagged  is:trash  is:missing
album:여행  album:여행+  album:none = 여행 앨범에 바로 든 그림 / 여행과 그 하위 앨범의 그림 / 무소속
                     (검색 뷰의 앨범을 누르면 album:여행+ 를 넣어 줌, album:여행+|album:바다+ = 둘 중 하나.
                      이름이 같은 앨범이 또 있으면 album:여행/바다 처럼 경로로, 띄어쓰기가 있으면 "album:내 앨범" 처럼 따옴표.
                      앨범 이름을 바꾸면 검색칸의 이름도 따라 바뀜. 예전 번호 album:3 도 됨)
added:today  added:yesterday  added:3d(최근 3일)  added>=11-01  = 넣은 날짜 (오늘/어제 도 됨)
date:2026-11-15  date<2026-01-01  = 파일 날짜
sort:new / old / name / score / seed / size / random   (검색에 sort: 가 있으면 정렬칸에 "(검색)" 표시)
조건은 콤마로 나눔:  long hair, scar, #pixiv  = 모두 맞는 것.  a|b = 둘 중 하나.
검색칸 왼쪽을 OR 로 두면 콤마로 나눈 태그·해시태그는 하나라도 맞으면 됨 (점수·앨범 같은 필터와 - 조건은 그래도 좁힘).
치는 동안 마지막 말은 그 글자로 시작하는 태그까지 보여 줌 (so → solo, #pix → #pixiv. 검색칸 오른쪽에 작게 표시).
Enter = 확정 (정확히 그 태그). 다른 곳을 눌러도 보이던 그림은 그대로.
저장한 검색·최근 검색은 OR 를 a|b 로 풀어 적어 둠 → 언제 불러도 뜻이 같음 (콤마가 든 것을 부르면 AND 로 바뀜).
그 밖의 글자는 프롬프트 태그를 통째로 찾음 (띄어쓰기 = _, 대소문자·가중치 무시. 해시태그·프리셋 이름도).
프롬프트는 콤마·줄바꿈과 문장 끝 마침표에서 나눔: "solo. A girl. jojo pose" → solo / a girl / jojo pose.
__scar__ / __scar / scar__ = scar가 들어간 / scar로 끝나는 / scar로 시작하는 태그.  파일 이름은 name:, 체크포인트는 ckpt:
왼쪽 목록을 누르면 검색에 넣고 빼 줌: 검색칸 왼쪽 AND = 새 조건, OR = 같은 종류의 마지막 조건에 | 로 (하나라도, 다른 종류 필터는 그대로 좁힘).
Ctrl+클릭 = 그 종류는 이것만. 오른쪽 클릭 = '이것 빼고' (점수는 '이상').
자주 쓰는 검색은 왼쪽 "＋ 지금 검색을 필터로 저장". 저장한 검색 오른쪽 클릭 = 이름 바꾸기·지금 검색으로 덮기·순서·지우기.
▾ = 최근 검색 다시 쓰기.
```

## 비교열 (C) — 여러 묶음을 줄줄이 놓고 비교

```text
그림이나 앨범을 오른쪽 클릭 → '비교열에 추가' (Shift+C) 또는 '비교열 비우고 추가'. 한 번 넣은 것이 한 줄 (몇 장이든).
고른 그림은 한 줄로, 고른 앨범은 앨범마다 한 줄로 (하위 앨범의 그림까지, 지금 정렬 순서). 왼쪽 앨범 목록 오른쪽 클릭에도 있음.
위의 [비교열 N] 또는 C = 비교열 보기·닫기. 비교열은 꺼도 남음 (50줄, 한 줄 300장까지).
줄마다 왼쪽 위 ✕ = 그 줄 지우기 (그림은 그대로), ⤒ ↑ ↓ ⤓ = 맨 위·위·아래·맨 아래로. 위의 '모두 비우기', '한 화면에 1·2·3줄'.
휠 = 위아래, Shift+휠 = 좌우, 끌기 = 이동 (확대했을 땐 그림 안에서 이동), 스크롤바도 있음.
Ctrl+휠 = 확대 (모든 칸에 같이) → 눈·손 같은 부분을 같은 자리끼리 비교. R = 맞춤.
칸마다 위에 프리셋·체크포인트·시드 (모든 줄 통틀어 서로 다른 부분은 밝게). 칸은 줄마다 같은 크기라 같은 열끼리 위아래로 맞음.
칸 클릭 또는 ←→↑↓ 로 칸 고르고 (Home·End = 줄 처음·끝, PageUp·PageDown = 한 화면만큼) 1~6 = 그 칸 점수.
더블클릭·Enter·Space = 크게: ←/→ 는 그 줄 안에서 넘김, Esc 하면 확대한 그대로 비교열로 돌아옴. 오른쪽 클릭 → '이 줄에서 빼기'.
같은 그림들의 줄은 두 번 안 들어감. 줄 지우기·모두 비우기·비우고 추가·줄에서 빼기는 Ctrl+Z로 되돌림.
표 비교(M)에서 C = 지금 행을 비교열에 한 줄로 넣고 바로 보기.
```

## 표 비교 (M) — 체크포인트·프리셋 시험 결과 한눈에

```text
행 = 시드(같은 큐로 뽑은 그림), 열 = 프리셋 / 체크포인트 / LoRA 조합 (위에서 고름).
지금 검색에 보이는 그림만 씀 → 먼저 검색으로 범위를 좁히고 M.
칸 클릭·방향키 이동, 1~6 점수, 더블클릭 = 크게. 열 제목 오른쪽 클릭 = 그 열 숨기기.
```

## 앨범 (A) — imgr 안에서만 쓰는 분류 (imgs의 진짜 폴더·파일은 그대로)

```text
그림 하나가 여러 앨범에 같이 들어갈 수 있음. 앨범 안에 하위 앨범도 만들 수 있음.
"무소속" = 맨 위(/)에만 있고 다른 앨범에는 없는 그림. 새 그림은 맨 위에 들어감. 그림 넣기·빼기·옮기기는 Ctrl+Z로 되돌릴 수 있음.
앨범 옮기기·지우기·이름 바꾸기와 가져오기는 Ctrl+Z로 안 돌아옴 (Ctrl+Z 하면 그렇다고 알려 주고, 한 번 더 누르면 그 앞의 것).
보는 방법이 둘:
  🗂 앨범 뷰 = 탐색기처럼 앨범을 폴더 칸으로 보기 (A, 왼쪽 앨범 뷰의 /·앨범)
  ▦ 검색 뷰 = 모든 그림에서 찾기 (Esc, 왼쪽 "전체 보기"). 왼쪽 검색 뷰의 "앨범"은 체크포인트처럼:
              클릭 = 그 앨범(하위 앨범의 그림까지)을 검색에 넣기·빼기 (AND/OR 에 따라), Ctrl+클릭 = 그 앨범만.
              다른 필터(점수·태그·체크포인트…)와 함께 거름
앨범 뷰:
  맨 위(/)에는 맨 위 앨범들, 그다음에 맨 위에 있는 그림.
  맨 위도 그냥 앨범 하나: 그림은 맨 위와 다른 앨범에 같이 있을 수 있고, 복사·옮기기·Del 모두 다른 앨범과 같은 규칙 (복사 = 원래 자리에도 남음, 옮기기 = 원래 자리에서 빠짐). 앨범 안에서는 하위 앨범 칸 다음에 그 앨범의 그림. 칸 사이 틈은 눌러도 아무 일 없음.
  새 앨범: Ctrl+N 또는 빈 곳 오른쪽 클릭 → "새 앨범…" (앨범 안이면 하위 앨범, 맨 위면 맨 위).
           이름 넣고 '만들기'를 눌러야 생김 (취소하면 안 생김). 위의 "＋ 새 앨범"도 같음.
  앨범 칸 클릭 = 바로 열기.
  고르기: 앨범은 Ctrl+클릭, Shift+클릭, 빈 곳에서 끌어 네모로, 오른쪽 클릭 (그림과 앨범을 같이 고를 수도 있음).
          방향키·PageUp/Down·Home/End도 앨범 칸과 그림을 한 줄로 이어서 움직임 (Shift = 범위). 무소속에서 Enter = 열기.
  오른쪽 클릭: 앨범 = 열기·하위 앨범·이름 바꾸기·잘라 두기·지우기 / 그림 = 그림 메뉴 ("'앨범'에서 빼기" 포함)
  Enter = 고른 앨범 열기.  F2 = 이름 바꾸기.
  Del: 고른 그림 = 이 앨범에서만 빼기 (다른 앨범에 든 것은 그대로).
       그 앨범이 그림의 마지막 앨범이면 imgr 휴지통으로 (is:trash에서 Del 또는 Ctrl+Z로 되살림).
       고른 앨범 = 앨범 지우기(묻고 나서). 앨범만 없어지고 그림은 그대로, 하위 앨범은 한 칸 위로.
  Shift+Del: 고른 그림 = imgr 휴지통으로 (모든 앨범에서 안 보임, Ctrl+Z·되살리기 하면 앨범도 그대로).
        고른 앨범 = 앨범과 하위 앨범, 그 안의 그림까지 지우기(묻고 나서). 그림은 imgr 휴지통으로, 앨범은 안 돌아옴.
  ⚙ 설정의 "Del 과 Shift+Del 을 서로 바꾸기"로 두 키를 맞바꿀 수 있음.
  옮기기: 그림·앨범을 다른 앨범(칸·위의 경로·왼쪽 앨범 뷰)에 끌어 놓기 = 이 앨범에서 빠지고 그리로 옮겨짐
          (그림은 Ctrl을 누른 채 놓으면 복사 = 이 앨범에도 남음. 앨범 칸은 고르지 않아도 바로 끌 수 있음)
          또는 Ctrl+X → 옮길 곳 열고 Ctrl+V.  맨 위도 같음: 위의 "🗂 앨범"·왼쪽 /에 놓기 = 맨 위로 옮기기 (Ctrl = 복사), 맨 위에서 Ctrl+V = 맨 위에도 두기.
  넣기:   고른 그림을 앨범에 끌어다 놓기 / Ctrl+C → 앨범 열고 Ctrl+V / 그림 오른쪽 클릭 → 앨범
  Ctrl+↑ · Alt+↑ · Backspace · Esc · 마우스 뒤로 버튼 = 한 칸 위.  위의 경로(앨범 › 여행 › 바다)를 눌러도 됨.
  그림을 고르면 오른쪽 칸 맨 위에 크게 보임.
  앨범 뷰에서 검색칸에 글자를 넣거나 검색 뷰의 필터를 누르면 검색 뷰로 바뀜.
오른쪽 정보 칸의 "앨범" = 그 그림이 든 앨범들 (누르면 그 앨범 열기).
프리셋 값 자체는 파일 이름 g_<프리셋>_<번호>에서만 읽어 두고(손으로 정하기는 없어짐) 표 비교·비교열에서만 씀.
```

## 지우기

```text
Del = imgr 휴지통으로 (목록에서 숨김, 파일은 그대로). Ctrl+Z 되돌리기.
왼쪽 앨범 뷰의 "휴지통"(또는 is:trash)으로 휴지통 보기, 거기서 Del = 되살리기. 휴지통 줄 오른쪽 클릭 = 비우기.
아래 "휴지통 비우기" = 그 파일들을 윈도우 휴지통으로 보냄 (윈도우 휴지통에서 되살릴 수 있음).
is:missing = imgs에서 파일이 없어진 기록(점수·태그·앨범이 있던 것만). ⚙ 설정에서 기록 지우기.
```

## 그 밖

```text
F1 = 검색 문법·단축키.  F5 = imgs 다시 읽기 (45초마다 저절로도 읽음)
Ctrl+Z = 점수·태그·앨범·휴지통 되돌리기
```
