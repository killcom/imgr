# imgr

English: [README.md](README.md)

윈도우용 그림 관리 프로그램입니다. 탐색기 대신 쓰려고 만들었고, 특히 ComfyUI 같은 AI 생성 그림을 많이 쌓아 두고 고르는 일에 맞춰져 있습니다.

## 할 수 있는 일

- **점수(1~6)·해시태그**: 키 하나로 매기고, 여러 장에 한꺼번에.
- **앨범**: imgr 안에서만 쓰는 분류입니다. 그림 하나가 여러 앨범에 들 수 있고, 하위 앨범도 됩니다. 탐색기처럼 끌어 놓기·Ctrl+X/C/V로 옮깁니다.
- **ComfyUI 정보**: PNG에 든 프롬프트·체크포인트·LoRA·시드를 읽어 보여 주고 검색합니다.
- **검색**: `#태그 score>=4 ckpt:이름 album:여행+ added:today` 처럼 조건을 이어 씁니다. 자주 쓰는 검색은 저장해 둡니다.
- **크게 보기·비교·표 비교**:
  - 여러 장을 나란히 놓고 같은 자리를 같이 확대할 수 있습니다.
  - 같은 시드끼리 체크포인트·프리셋을 표로 비교합니다.
- **가져오기**:
  - 창에 끌어 놓기, Ctrl+V, 폴더 지정, 자동 가져오기(폴더 지켜보기)를 지원합니다.
  - 같은 그림은 내용(해시)으로 알아보고 한 번만 넣습니다.
- **내보내기**: 업로드용으로 메타데이터를 지운 jpg/png 사본을 만들고, 무작위 이름을 붙입니다.
- 파일 내용으로 그림을 알아보므로, 폴더 안에서 옮기거나 이름을 바꿔도 점수·태그가 따라갑니다.

- **화면 언어**: 한국어 / English (⚙ 설정, 처음엔 윈도우 언어를 따름).

자세한 사용법: [docs/usage_ko.md](docs/usage_ko.md) · 프로그램 안에서는 F1.

## 받기

[Releases](../../releases) 페이지에서 `imgr_v…_win64.zip` 을 받아, 그림을 둘 폴더에 풀고 `imgr.exe` 를 실행합니다.

- zip은 GitHub Actions가 이 소스로 빌드합니다 (`.github/workflows/release.yml`).
- 코드 서명이 없어서 윈도우가 "PC 보호" 경고를 띄울 수 있습니다: **추가 정보 › 실행**.

## 필요한 것

- Windows 10 / 11 (64비트). 윈도우 전용입니다(탐색기 클립보드·끌어 놓기·휴지통을 씁니다).
- 한글 글꼴은 윈도우의 맑은 고딕을 씁니다.

## 빌드

1. [Rust](https://rustup.rs) (stable)와 Visual Studio Build Tools(C++)를 설치합니다.
2. 이 저장소 폴더에서 아래 명령을 실행합니다.
   ```
   cargo build --release
   ```
3. `target\release\imgr.exe` 를 그림을 둘 폴더에 복사해 실행합니다.

## 폴더

exe가 있는 폴더(또는 환경 변수 `IMGR_ROOT`)가 imgr의 자리입니다.

```
imgr.exe
imgs\00001\…    그림 (한 폴더에 2000장씩 채움, ⚙ 설정에서 바꿈)
data\           기록: db.json(점수·태그·앨범…), settings.json, 썸네일 캐시, 백업
```

- 모든 기록은 이 폴더 안에만 둡니다. 인터넷으로 아무것도 보내지 않습니다.
- 스크립트 조작(시험·자동화용)은 처음엔 꺼져 있습니다.
  - 켜는 법: ⚙ 설정의 "스크립트 조작 허용"을 켜거나, 환경 변수 `IMGR_CTL=1`로 실행합니다.
  - 켜면 이 PC 안에서만 `127.0.0.1:47811`로 명령을 받고, 웹 페이지에서 온 요청은 거절합니다.
  - `tools/imgr_ctl.py`가 명령을 보내는 예입니다.

## 코드 구조

| 파일 | 하는 일 |
|---|---|
| `src/db.rs` | 기록, 폴더 읽기·맞추기, 가져오기, 이름 바꾸기, PNG/ComfyUI 정보 |
| `src/query.rs` | 검색 문법, 정렬 (단위 시험 포함) |
| `src/library.rs` | 사전: ComfyUI 작업 폴더의 캐릭터·의상·표정·포즈·프리셋 파일 |
| `src/ops.rs` | 내보내기, 지켜보는 폴더 |
| `src/winshell.rs` | Win32: 파일 클립보드, 끌어 내보내기, 탐색기에서 보기, 창 하나만 |
| `src/thumbs.rs` | 썸네일 읽기·디스크 캐시 |
| `src/ctl.rs` | 조작 명령 받기 (localhost HTTP) |
| `src/i18n.rs` | 화면 언어 (한국어 / English) |
| `src/app.rs`, `src/app/` | 화면과 동작 (위·왼쪽·오른쪽 칸, 그리드, 앨범 뷰, 크게 보기·비교, 사전, 창들) |

단위 시험: `cargo test`

새 판 내기: `Cargo.toml` 판 번호를 올리고 `CHANGELOG.md`에 `## v0.14` 부분을 쓴 뒤, 태그 `v0.14`를 올리면 GitHub가 빌드·시험하고 `imgr_v0.14_win64.zip`을 Releases에 붙입니다 (`tools/package.ps1`로 손으로도 같은 zip을 만듦).
